Cách tạo token giới hạn quyền

Trên GitHub chọn New fine-grained token → Repository access: Only select repositories → chọn tuvung → Repository permissions: Contents Read and write → Generate token. Chỉ dán token vào trang web của chính bạn, không đưa vào file hoặc gửi cho người khác.

Từ được lưu tạm trên thiết bị. Khi đã kết nối, thay đổi sẽ tự ghi vào words.json trên GitHub. Nếu chưa kết nối, từ mới sẽ chờ đồng bộ trên thiết bị này.
